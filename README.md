# 💕 Landing Page for My Ayang

> *"A landing page is also an exercise for TOP. But I'll make something more interesting to motivate me."*

This project started as an exercise from [The Odin Project](https://www.theodinproject.com/) (Foundations Course — Landing Page), but I decided to make it **mine**. Instead of a generic business template, I built a love letter in code for the person who keeps me going.

---

## 🎯 What This Is

| Aspect | Description |
|--------|-------------|
| **Exercise** | TOP Foundations — Flexbox Landing Page |
| **Purpose** | Practice HTML, CSS (Flexbox), Git workflow, and deployment |
| **Motivation** | My ayang — the reason I push through the hard days |
| **Status** | 🚧 Work in Progress (MVP done, polishing ongoing) |

---

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Flexbox layout, custom styling
- **Git & GitHub** — Version control & deployment
- **VS Code + WSL** — Development environment

## 🧠 hat I Learned

- ✅ Relative vs absolute file paths (`my-ayang/` vs `/my-ayang/`)
- ✅ Git workflow: `add` → `commit` → `push`
- ✅ Flexbox for centering and layout
- ✅ Staging vs committing (don't forget to commit before pushing! 😅)
- ✅ Organizing assets in subdirectories
